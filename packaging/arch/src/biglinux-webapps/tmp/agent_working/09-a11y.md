## VM walk checklist (linux-ui-a11y skill)

```
dbus-run-session bash <<'EOS'
  kwin_wayland --virtual --width=1280 --height=900 --no-lockscreen \
    --xwayland big-webapps-gui &
  sleep 2
  python3 - <<'PY'
import pyatspi
def walk(node, depth=0):
    role = node.getRoleName()
    name = node.name or ""
    print(f"{' '*depth*2}{role:30s} {name!r}")
    for child in node:
        walk(child, depth+1)
walk(pyatspi.Registry.getDesktop(0))
PY
EOS
```

Expected: zero `('push button', '')` rows; zero rows with `role=label` carrying interactive meaning. Filed as `09-a11y-vm.md` after run.
